# ניתוח מתחרים — תבנית

## מקורות
- אתר המתחרה: כותרת ראשית, דפי שירות, מחירים, אודות, תיק עבודות
- תוכן אחרון: בלוג, רשתות, מודעות פעילות (ספריית המודעות של מטא)
- ביקורות: גוגל, פייסבוק — נושאים חוזרים בשבח ובתלונה
- סימני כיוון: משרות פתוחות, שירותים חדשים

## מבנה
### 1. שורה תחתונה
2–3 משפטים: ההזדמנות הגדולה והאיום הגדול לדיבנט.

### 2. פרופיל לכל מתחרה
- מה הם במשפט אחד, למי
- מסר מרכזי ו-3 נושאים חוזרים, טון
- שירותים ומבדלים מוצהרים, מחיר (רק אם פורסם)
- חוזקות / חולשות (כולל תלונות מביקורות)

### 3. טבלת השוואה

|---|---|---|---|
| כותרת ראשית | | | |

| מבדל | | | |
| מחיר/מודל | | | |

### 4. פערים והזדמנויות
זוויות מסר פנויות, קהלים לא משורתים, ערוצים ופורמטים שאף אחד לא מנצל.

### 5. מה עושים עם זה
3 פעולות קונקרטיות לדיבנט, מתועדפות.
