# Google Maps Scraper Kit - איסוף עסקים מ-Google Maps

ערכת כלים לאיסוף רשימות עסקים מ-Google Maps לפי שאילתה ואזור, וייצוא שלהן
ל-CSV (נפתח נכון ב-Excel) או ל-JSON: שם, כתובת, קואורדינטות, טלפון, אתר,
דירוג, מספר ביקורות, שעות פתיחה ותוכן ביקורות.

## למה API רשמי ולא גירוד HTML

הכלים כאן עובדים מול **Places API הרשמי** של Google ולא מגרדים את
`maps.google.com`. זו החלטה מכוונת:

- גירוד ממשק המשתמש של Maps מפר את תנאי השימוש של Google.
- הוא נשבר בכל שינוי עיצוב, ומוביל לחסימת IP ול-CAPTCHA.
- ה-API מחזיר את אותם נתונים בצורה מובנית, יציבה ומותרת לשימוש.

בתמורה: צריך מפתח API, וכל קריאה עולה כסף. הכלים בנויים כדי למזער את זה -
מטמון מקומי, מפלסי שדות, ו-`--dry-run` לאמידת עלות מראש.

**שימו לב לתנאי השימוש:** נתוני Places מיועדים לשימוש בהתאם ל-Google Maps
Platform Terms of Service - יש הגבלות על אגירה (caching) ארוכת-טווח ועל
הצגה מחדש של הנתונים. בדקו את התנאים לפני שאתם בונים מוצר על הפלט.

## מבנה

```
maps/
  places_api.py      # המנוע: אימות, field masks, backoff, מטמון, ספירת קריאות
  search.py          # CLI: חיפוש עסקים לפי שאילתה ואזור -> CSV/JSON
  details.py         # CLI: העשרה בפרטים מלאים וביקורות
  requirements.txt
scripts/
  scrape.sh          # עוטף מקוצר: "שאילתה" lat lng radius -> CSV+JSON ב-out/
```

## התקנה

```bash
pip install -r maps/requirements.txt
```

הפעילו את **Places API (New)** ואת **Geocoding API** בפרויקט Google Cloud
שלכם, צרו מפתח, והגדירו אותו:

```bash
export GOOGLE_MAPS_API_KEY="..."
```

משתני סביבה נוספים (אופציונליים): `GOOGLE_MAPS_LANGUAGE` (ברירת מחדל `he`),
`GOOGLE_MAPS_REGION` (ברירת מחדל `IL`), `GOOGLE_MAPS_CACHE` (ברירת מחדל
`.maps_cache`).

## שימוש

### חיפוש בסיסי

```bash
python maps/search.py "מסעדות" --location "תל אביב" --radius 5 --csv out.csv
```

### עוטף מקוצר: scripts/scrape.sh

לשימוש מהיר יש עוטף עם ממשק פוזיציוני (שאילתה, קו רוחב, קו אורך, רדיוס בק"מ):

```bash
./scripts/scrape.sh "coffee shops in Austin TX" 30.2672 -97.7431 5
```

העוטף שומר אוטומטית CSV ו-JSON עם חותמת זמן ל-`out/`, ומעביר כל דגל נוסף
ישר ל-`search.py`:

```bash
./scripts/scrape.sh "מסעדות" 32.0853 34.7818 10 --grid 3 --auto-split
./scripts/scrape.sh "מוסך" 31.2530 34.7915 8 --dry-run
```

בניגוד ל-`search.py`, ברירת המחדל של העוטף היא **en/US** (לא he/IL), כי הוא
נועד גם לחיפושים מחוץ לישראל. לשינוי:

```bash
SCRAPE_LANGUAGE=he SCRAPE_REGION=IL ./scripts/scrape.sh "מסעדות" 32.0853 34.7818 5
```

משתני סביבה: `SCRAPE_LANGUAGE` (ברירת מחדל `en`), `SCRAPE_REGION` (`US`),
`SCRAPE_TIER` (`contact`), `OUT_DIR` (`out`), `PYTHON` (`python3`).

דגלים שאתם מוסיפים מנצחים את ברירות המחדל של העוטף, כולל `--csv`/`--json`
(argparse לוקח את הערך האחרון). העוטף בודק טווחי קואורדינטות ורדיוס, קיום
מפתח API והתקנת `requests` **לפני** שהוא שולח קריאה בתשלום.

העוטף הוא ממשק שורת פקודה סינכרוני - אין כאן שירות, תור עבודות או REST API.

### כיסוי אזור שלם (מעבר ל-60 תוצאות)

כל שאילתה ב-Places API מחזירה **לכל היותר 60 תוצאות** (3 עמודים של 20). כדי
לאסוף מאות עסקים, הכלי מחלק את האזור לרשת תאים ושולח שאילתה לכל תא בנפרד:

```bash
# רשת 3x3 על רדיוס 15 ק"מ, עם פיצול אוטומטי של תאים "רוויים"
python maps/search.py "מספרה" --location "תל אביב" --radius 15 \
    --grid 3 --auto-split --csv barbers.csv --json barbers.json
```

`--auto-split` הוא הלב של הכיסוי: תא שהחזיר 60 תוצאות כמעט בוודאות "נחתך",
ולכן הוא מפוצל לארבעה תאים קטנים והסריקה נמשכת בהם (עד `--max-depth`, ברירת
מחדל 3). התוצאות מאוחדות לפי `place_id` בלי כפילויות.

### אמידת עלות לפני הרצה

```bash
python maps/search.py "מוסך" --location "באר שבע" --radius 8 --grid 3 --dry-run
```

מדפיס את התאים שייסרקו ואת מספר הקריאות המקסימלי - בלי לשלוח שום קריאה בתשלום.

### סינון

```bash
python maps/search.py "בית קפה" --center 32.0853,34.7818 --radius 3 \
    --type cafe --min-rating 4 --open-now --max-results 300 --csv cafes.csv
```

`--type` מקבל סוג מקום של Places (למשל `restaurant`, `dentist`, `car_repair`);
`--strict-type` מחזיר רק התאמות מדויקות לסוג.

### העשרה בפרטים וביקורות

```bash
python maps/details.py --input cafes.json --csv cafes_full.csv --json cafes_full.json
```

מוסיף עמודת `reviews_text` עם עד 5 ביקורות לעסק (מגבלת ה-API). הקובץ הנכנס
יכול להיות ה-JSON או ה-CSV של `search.py`, או רשימת `place_id` בשורת הפקודה.

## מפלסי שדות ועלות

המחיר לאלף קריאות ב-Places API נקבע לפי אילו שדות ביקשתם, ולכן הכלים חושפים
`--tier`:

| מפלס | מה כלול | מתי להשתמש |
|------|---------|-------------|
| `basic` | שם, כתובת, מיקום, סוג, קישור ל-Maps | מיפוי וספירה - הזול |
| `contact` | + טלפון, אתר, דירוג, שעות פתיחה, רמת מחיר | ברירת המחדל, מתאים לרוב השימושים |
| `full` | + ביקורות ותקציר עריכה | ניתוח סנטימנט - היקר |

בסוף כל הרצה הכלי מדפיס כמה קריאות בתשלום בוצעו, לפי מפלס. את המחיר המעודכן
לאלף קריאות יש לבדוק במחירון Places API של Google (הוא משתנה מדי פעם, ולכן
הכלי מדפיס ספירות ולא סכומים).

דרכים להוזיל:

- **מטמון** - כל תשובה נשמרת ב-`.maps_cache/`. הרצה חוזרת של אותה שאילתה לא
  מחייבת שוב. `--no-cache` מבטל.
- **`--dry-run`** לפני כל סריקה רחבה.
- **`--tier basic`** לאיסוף ראשוני, ואז `details.py` רק על מה שסוננו.
- **`--max-results`** כדי לעצור בגבול מוגדר.
- **`--qps`** להגבלת קצב אם אתם נתקלים ב-429.

## מגבלות ידועות

- 60 תוצאות לשאילתה (מגבלת API) - נעקפת חלקית עם `--grid` / `--auto-split`,
  אך באזורים צפופים מאוד עדיין אפשר לפספס עסקים.
- עד 5 ביקורות לעסק, ולא ניתן לשלוף את כולן.
- אימייל של עסק אינו זמין ב-API (Google לא מספקת אותו).
- `--auto-split` מכפיל קריאות: כל פיצול מוסיף עד 12 קריאות לתא. התחילו קטן.
