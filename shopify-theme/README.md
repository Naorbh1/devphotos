# Convert — תבנית חנות גנרית לשופיפיי

ערכת עיצוב (theme) מלאה לשופיפיי, בנויה מאפס, בלי תלויות חיצוניות.
כל העיצוב נשלט מהגדרות התבנית — אפשר להחליף סגנון תצוגה שלם בלי לגעת בקוד.

**עברית ו‑RTL נתמכים מלכתחילה**: כיוון הדף נקבע לפי שפת החנות, וכל ה‑CSS
משתמש בתכונות לוגיות (`inset-inline-start` במקום `left`) כך שהפריסה מתהפכת
נכון בעברית.

---

## מה יש בפנים

```
shopify-theme/
  assets/        base.css, theme.js            — כל ה‑CSS וה‑JS
  config/        settings_schema.json          — הגדרות התבנית + 5 סגנונות מוכנים
  layout/        theme.liquid, password.liquid
  locales/       en.default + he (ממשק ולוח הבקרה)
  sections/      21 סקשנים
  snippets/      18 סניפטים
  templates/     כל התבניות (JSON) + עמודי לקוח
  docs/          תבנית CSV לייבוא מוצרים + מבנה חנות ותוכן
```

## התקנה

### דרך Shopify CLI (מומלץ)

```bash
npm install -g @shopify/cli
cd shopify-theme
shopify theme dev --store your-store.myshopify.com   # תצוגה חיה עם רענון אוטומטי
shopify theme push --unpublished                      # העלאה כטיוטה
```

### דרך ZIP

```bash
cd shopify-theme && zip -r ../convert-theme.zip . -x '.*'
```

ואז: **Online Store → Themes → Add theme → Upload zip file**.

### בדיקת תקינות

```bash
shopify theme check
```

התבנית עוברת את `theme-check:recommended` נקי — 75 קבצים, אפס הערות.

## החלפת סגנונות תצוגה

זה הלב של התבנית. **Online Store → Customize → Theme settings → סגנון**.

| הגדרה | מה היא משנה |
|---|---|
| **סגנון תצוגה** | 5 פריסטים: מודרני, מינימלי, נועז, מגזיני, שובב. משנה עובי כותרות, ריווח אותיות, טיפול בתוויות ועומק הצללים בכל האתר בבת אחת |
| **צפיפות** | צפוף / נוח / מרווח — כל הריווחים בעמוד |
| **עיגול פינות** | 0–24px, חל על כרטיסים, כפתורים, תמונות ושדות |
| **סגנון כרטיס** | שטוח / מסגרת / צל רך / מוגבה |
| **צורת כפתורים** | מרובע / מעוגל / עגול מלא |
| **יחס תמונה** | ריבוע, לאורך, גבוה, לרוחב |
| **רוחב עמוד, מרווח רשת, מרווח סקשנים** | ממשיים בפיקסלים |

בנוסף יש 5 פריסטים מוכנים ב‑`config/settings_data.json` שמחליפים גם צבעים
וגופנים יחד עם הסגנון (Modern / Minimal / Bold / Editorial / Playful).

**איך זה עובד טכנית:** `layout/theme.liquid` כותב את כל ההגדרות כמשתני CSS
על `:root`, ומוסיף מחלקות (`style-bold`, `cards-shadow`, `density-spacious`)
על ה‑`<html>`. `base.css` מכוון את אותם משתנים לפי המחלקות. אין CSS כפול
לכל סגנון — רק ערכים שונים לאותם משתנים.

### תצוגות שונות לכל קטגוריה

בעמוד קטגוריה יש **מחליף תצוגה** (רשת / רשת גדולה / רשימה) שהלקוח בוחר,
והבחירה נשמרת ב‑localStorage. בסקשן "קטגוריה מומלצת" בדף הבית אפשר לבחור
לכל מופע בנפרד: **רשת / קרוסלה / רשימה / רשת משורגת**, כמות עמודות בדסקטופ
ובמובייל, ויחס תמונה — כך שאותה תבנית נותנת מראה שונה לכל קטגוריה.

## הוספה מהירה לסל

מופעל כברירת מחדל (**הגדרות → המרות → הוספה מהירה מכרטיס המוצר**).

- **מוצר בלי וריאנטים** — לחיצה אחת מוסיפה לסל דרך AJAX, בלי לעזוב את העמוד.
- **מוצר עם וריאנטים** — נפתח בורר אפשרויות מעל הכרטיס. הוא מוודא שהצירוף
  שנבחר קיים וזמין לפני שהוא מוסיף. אף אחד לא מקבל מידה שלא בחר.
- אחרי ההוספה נפתחת מגירת הסל וקופצת הודעת אישור.
- בלי JavaScript הכפתורים עדיין עובדים — הטפסים נשלחים לשופיפיי כרגיל.

## תוספי המרה שכלולים

הכל בנוי פנימה, בלי אפליקציות בתשלום:

| תוסף | איפה מגדירים |
|---|---|
| מגירת סל נשלפת (AJAX) | הגדרות → המרות → התנהגות הסל |
| הוספה מהירה מכרטיס המוצר | הגדרות → המרות |
| כפתור הוספה דביק בעמוד המוצר | הגדרות → המרות |
| סרגל התקדמות למשלוח חינם | הגדרות → המרות (בסל ובמגירה) |
| מונה מלאי נמוך ("נותרו 3 בלבד") | הגדרות → המרות — **רק כשהמלאי באמת נמוך ובאמת נספר** |
| Upsell בסל | אוטומטי — משתמש במוצרים משלימים מ‑Search & Discovery |
| מוצרים מומלצים | סקשן בעמוד המוצר, מנוע ההמלצות של שופיפיי |
| נצפו לאחרונה | סקשן, נשמר ב‑localStorage בלבד |
| פופאפ אימייל (השהיה + exit intent) | הגדרות → המרות → פופאפ אימייל |
| סרגל הודעות מתחלף + ספירה לאחור | סקשן "סרגל הודעות" |
| ספירה לאחור בבאנר הראשי | סקשן "באנר ראשי" |
| חיפוש חוזה (predictive search) | מובנה בכותרת העליונה |
| מסננים ומיון בקטגוריה | סקשן "קטגוריה" — משתמש במסננים של שופיפיי |
| תגיות אמון + אייקוני תשלום | בלוק בעמוד המוצר ובפוטר |
| דירוגי כוכבים | קורא את מטא־שדה `reviews` שרוב אפליקציות הביקורות כותבות אליו |
| שיתוף (פייסבוק / וואטסאפ / מייל) | בלוק בעמוד המוצר |
| Rich results בגוגל | JSON‑LD למוצר, לשאלות נפוצות, לארגון ולחיפוש באתר |

> **הערה על מלאי:** מונה המלאי מציג מספר אמיתי בלבד. הוא לא מוצג אם המלאי
> לא נספר בשופיפיי. סתם "נותרו 2!" מזויף הוא הדרך המהירה לאבד לקוח חוזר.

## מה עוד צריך להגדיר בלוח הבקרה

התבנית לא יכולה להגדיר במקומך:

1. **תפריטים** — Navigation → `main-menu` ו‑`footer`.
2. **מסננים** — Navigation → Filters (בלעדיהם הסקשן פשוט לא מציג מסננים).
3. **תעריפי משלוח** — Settings → Shipping. ודא שסף המשלוח חינם בהגדרות
   התבנית תואם לתעריף האמיתי.
4. **מוצרים משלימים** — אפליקציית Search & Discovery (חינמית), כדי שה‑upsell
   בסל יהיה רלוונטי ולא אקראי.
5. **עמודי מדיניות** — Settings → Policies.
