# מבנה חנות ותוכן מוכן

מסמך עבודה: מה לבנות בלוח הבקרה של שופיפיי, באיזה סדר, ואיזה טקסטים להדביק.
כל הטקסטים כאן גנריים בכוונה — החליפו את מה שבסוגריים מרובעים.

---

## 1. מבנה קטגוריות (Collections)

בנו 3 שכבות. אל תיצרו יותר מ‑2 רמות עומק — קטגוריה בעומק שלישי כמעט אף פעם
לא מקבלת תנועה.

**קטגוריות ניווט (ידניות, מופיעות בתפריט):**

| Handle | שם | תיאור קצר לעמוד |
|---|---|---|
| `all` | כל המוצרים | הקטלוג המלא. |
| `[category-1]` | [שם קטגוריה 1] | [משפט אחד: למי זה ומה מייחד] |
| `[category-2]` | [שם קטגוריה 2] | |
| `[category-3]` | [שם קטגוריה 3] | |

**קטגוריות אוטומטיות (לפי תנאי — לא ידניות, מתעדכנות לבד):**

| Handle | שם | תנאי |
|---|---|---|
| `new-arrivals` | חדש באתר | Product tag is equal to `new` |
| `best-sellers` | הנמכרים ביותר | Product tag is equal to `best-seller` |
| `sale` | מבצעים | Compare at price is greater than 0 |
| `frontpage` | דף הבית | ידני — 8–12 מוצרים שאתם רוצים לדחוף |

> `frontpage` חשובה: התבנית משתמשת בה כברירת מחדל ל‑upsell בסל כשעדיין אין
> מוצרים משלימים מוגדרים.

## 2. תפריטים (Navigation)

**`main-menu`:**
```
חדש באתר        → /collections/new-arrivals
[קטגוריה 1]     → /collections/[category-1]
    ├ [תת‑קטגוריה]
    └ [תת‑קטגוריה]
[קטגוריה 2]     → /collections/[category-2]
מבצעים          → /collections/sale
אודות           → /pages/about
צרו קשר         → /pages/contact
```

**`footer`:**
```
אודותינו        → /pages/about
משלוחים והחזרות → /pages/shipping-returns
שאלות נפוצות    → /pages/faq
צרו קשר         → /pages/contact
תקנון ותנאי שימוש → /policies/terms-of-service
מדיניות פרטיות  → /policies/privacy-policy
```

## 3. מסננים (Navigation → Filters)

הפעילו לפחות: **מחיר**, **זמינות**, ואת אפשרויות המוצר שרלוונטיות
(מידה / צבע / חומר). סקשן הקטגוריה בתבנית מציג אוטומטית כל מסנן שתפעילו —
בלי מסננים מופעלים הוא פשוט לא יציג את האזור הזה.

## 4. עמודים (Pages)

### `about` — אודות

> **[כותרת: משפט אחד על מה אתם עושים]**
>
> [2–3 פסקאות. ספציפי מנצח מפואר: מאיפה מגיעים החומרים, מי מייצר, מה
> ההחלטה שקיבלתם שמתחרים לא מקבלים. אל תכתבו "איכות ללא פשרות" — כתבו
> מה בדיוק לא מתפשרים עליו.]
>
> **למה זה שונה**
> - [יתרון קונקרטי 1 — עם מספר אם אפשר]
> - [יתרון קונקרטי 2]
> - [יתרון קונקרטי 3]

### `shipping-returns` — משלוחים והחזרות

> **משלוחים**
> הזמנות יוצאות תוך [1–2] ימי עסקים. זמן אספקה משוער: [3–5] ימי עסקים.
> משלוח חינם בהזמנות מעל [₪200]. משלוח מהיר: [₪XX], אספקה תוך [24 שעות].
>
> **החזרות**
> ניתן להחזיר כל פריט שלא נעשה בו שימוש תוך [30] יום מקבלת ההזמנה, באריזתו
> המקורית. ההחזר מבוצע לאמצעי התשלום המקורי תוך [5–7] ימי עסקים מרגע
> קבלת ההחזרה.
>
> **איך מחזירים**
> 1. שולחים מייל ל‑[email] עם מספר ההזמנה.
> 2. מקבלים תווית החזרה.
> 3. מוסרים בנקודת האיסוף הקרובה.
>
> **החלפות** — [מדיניות]. **פריטים שלא ניתן להחזיר** — [רשימה].

### `faq` — שאלות נפוצות

השתמשו בסקשן **FAQ** בעמוד (הוא מפיק JSON‑LD ויכול להופיע כתוצאה מורחבת
בגוגל). שאלות מומלצות:

1. כמה זמן לוקח המשלוח?
2. מה מדיניות ההחזרות?
3. האם אתם שולחים לחו״ל?
4. איך אני יודע איזו מידה להזמין? *(אם יש מידות)*
5. אילו אמצעי תשלום אתם מקבלים?
6. איך אני עוקב אחרי ההזמנה?
7. המוצר הגיע פגום — מה עושים?

### `contact` — צרו קשר

השתמשו בתבנית `page.contact` (כבר קיימת) — היא מוסיפה טופס אוטומטית.

## 6. מוצרים — מה חייב להיות בכל מוצר

- **שם** — [מה זה] + [המאפיין המבדיל]. לא "מוצר מדהים 2024".
- **תיאור** — 2–3 שורות ראשונות עונות "למה זה מתאים לי", ואז רשימת
  מפרט. הרשימה נסרקת, הפסקה נקראת.
- **5 תמונות לפחות** — ראשית על רקע נקי, שנייה בשימוש (זו מה שמופיעה
  ב‑hover בכרטיס), פרט מקרוב, קנה מידה, ואריזה.
- **טקסט חלופי (alt)** לכל תמונה — נגישות וגם SEO.
- **תגיות** — `new` ו‑`best-seller` מזינות את הקטגוריות האוטומטיות.
- **SEO title** — עד 60 תווים. **SEO description** — עד 155.
- **מחיר "לפני"** (Compare at price) רק אם המחיר באמת היה כזה.

## 7. ייבוא מוצרים ב‑CSV

`docs/products-import-template.csv` — הפורמט הרשמי של שופיפיי, מוכן לייבוא
דרך **Products → Import**.

**כללי הזהב של הפורמט:**

- `Handle` הוא המפתח. **כל שורה** של אותו מוצר חוזרת על אותו handle.
- רק **השורה הראשונה** של כל handle נושאת שם, תיאור, יצרן ותגיות. בשאר
  השורות משאירים ריק — אחרת שופיפיי דורס.
- כל שורה נוספת = **וריאנט נוסף**. `classic-tee` בקובץ מדגים 6 וריאנטים
  (3 מידות × 2 צבעים).
- למוצר בלי וריאנטים: `Option1 Name` = `Title`, `Option1 Value` = `Default Title`.
- `Image Src` צריך להיות URL ציבורי. השורות מוסיפות תמונות לגלריה לפי
  `Image Position`; `Variant Image` קובע איזו תמונה שייכת לאיזה וריאנט.
- `Variant Inventory Policy`: `deny` = לא ניתן להזמין באפס מלאי,
  `continue` = כן.
- `Cost per item` לא חובה, אבל בלעדיו אין דוחות רווחיות בשופיפיי.
- שמרו תמיד ב‑UTF‑8. אקסל בעברית נוטה לשמור ב‑Windows‑1255 והעברית תישבר —
  ב‑Excel בחרו **Save As → CSV UTF‑8**.

**קטגוריות לא מיובאות ב‑CSV** — אין ייבוא קולקציות בשופיפיי. צרו אותן ידנית
(או אוטומטיות לפי תגית, כמו בטבלה בסעיף 1) ואז שייכו מוצרים בבת אחת דרך
Products → בחירה מרובה → Add to collection.

## 8. צ'קליסט לפני העלאה לאוויר

**חובה:**
- [ ] תפריטים `main-menu` ו‑`footer` בנויים
- [ ] מסננים הופעלו ב‑Navigation → Filters
- [ ] תעריפי משלוח מוגדרים, וסף המשלוח חינם בתבנית **תואם** לתעריף האמיתי
- [ ] אמצעי תשלום פעילים (אייקוני התשלום בפוטר נשלפים מכאן אוטומטית)
- [ ] כל 4 עמודי המדיניות מולאו (Settings → Policies)
- [ ] לוגו ו‑favicon הועלו
- [ ] הזמנת בדיקה אמיתית בוצעה מקצה לקצה

**מומלץ:**
- [ ] אפליקציית Search & Discovery מותקנת + מוצרים משלימים הוגדרו
      (מפעיל את ה‑upsell בסל)
- [ ] אפליקציית ביקורות שכותבת למטא־שדה `reviews` (מפעילה כוכבים בכרטיסים
      וב‑rich results)
- [ ] תמונת שיתוף ברירת מחדל (הגדרות → רשתות חברתיות)
- [ ] קישורי רשתות חברתיות מולאו — כל שדה ריק פשוט לא מוצג
- [ ] נבדק במובייל אמיתי, לא רק בהקטנת חלון הדפדפן
- [ ] נבדק בעברית **ובאנגלית** אם החנות דו‑לשונית (הפריסה מתהפכת)

**כיול לפי נתונים אחרי שבועיים:**
- [ ] סף המשלוח חינם — כדאי שיהיה כ‑25%–30% מעל שווי ההזמנה הממוצע
- [ ] פופאפ האימייל כבוי כברירת מחדל. הפעילו רק אם יש לכם באמת מה לשלוח
- [ ] סגנון התצוגה — נסו preset אחר ומדדו, ההבדל בין "מינימלי" ל"נועז"
      אמיתי ומדיד
