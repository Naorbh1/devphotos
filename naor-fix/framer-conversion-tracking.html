ב-Google Ads: ליצור המרה לשיחת טלפון

  1. ליצור פעולת המרה חדשה

    1. ב-Google Ads: יעדים (Goals) ← המרות (Conversions) ← סיכום (Summary).
    2. ללחוץ + פעולת המרה חדשה ולבחור אתר (Website).
    3. להזין naor-fix.com וללחוץ סריקה (Scan).
    4. לגלול למטה וללחוץ + הוספת פעולת המרה באופן ידני.

  2. למלא את ההגדרות

    • קטגוריית יעד: ליד טלפוני (Phone call lead)
    • שם פעולת ההמרה:
    שם ההמרה
    לחיצה על טלפון באתר
    • ערך: לא להשתמש בערך
    • ספירה: אחת (One). שיחה אחת היא ליד אחד.
    • ללחוץ סיום ואז שמירה והמשך.

  3. להעתיק את מזהה ההמרה החדשה

    במסך ההתקנה לבחור התקנה עצמית של התג (Install the tag yourself). בקטע קטע קוד של אירוע (Event snippet) מופיעה שורה כזו:

    לדוגמה בלבד, אל תעתיק
    'send_to': 'AW-17515611746/AbCdEfGhIjKlMnOp'

    מעתיקים רק את החלק הצהוב, בלי הגרשיים, ומדביקים כאן:

    עוד לא הודבק מזהה. הקוד בשלב B יספור בינתיים לחיצות על הטלפון תחת "איש קשר".

    הקוד בשלב B מתעדכן אוטומטית עם המזהה שהדבקת. את תג הבסיס שגוגל מציג במסך הזה לא צריך להתקין. הוא כבר מופיע בשלב B.

  1. לפתוח את מסך הקוד

    1. לפתוח את הפרויקט של naor-fix ב-Framer.
    2. ללחוץ על גלגל השיניים Site Settings בסרגל העליון.
    3. בתפריט הצד לבחור General.
    4. לגלול למטה עד הכותרת Custom Code. שם מופיעים ארבעת השדות מהטבלה למעלה.

  2. לבדוק את תג הבסיס בשדה Start of <head> tag

    אם יש שם כבר סקריפט עם googletagmanager.com/gtag/js, לא מוסיפים אותו שוב. רק לוודא שיש בו את שתי שורות ה-config שמופיעות למטה, ואם השורה של AW-17515611746 חסרה, להוסיף אותה.

    אם השדה ריק, להדביק את כל הבלוק:

    Start of <head> tag · תג בסיס
    <!-- Google tag (gtag.js) -->
<script async src="https://www.googletagmanager.com/gtag/js?id=G-31BZDL3KQ3"></script>
<script>
  window.dataLayer = window.dataLayer || [];
  function gtag(){dataLayer.push(arguments);}
  gtag('js', new Date());
  gtag('config', 'G-31BZDL3KQ3');
  gtag('config', 'AW-17515611746');
</script>

  3. למחוק את הקוד הישן ששולח המרה בכל טעינה

    לחפש בכל ארבעת השדות את השורה הזו:

    השורה לחיפוש
    gtag('event', 'conversion', {'send_to': 'AW-17515611746/gxk3CNKHtPEcEOKMjKBB'});
    • למחוק: את השורה הזו, יחד עם ה-<script> שעוטף אותה אם היא לבד בתוכו.
    • להשאיר: את תג הבסיס משלב 2.

    אם היא לא נמצאת שם, צריך לבדוק גם בכל עמוד: לחיצה ימנית על העמוד ברשימת העמודים ← Settings ← Custom Code. הכי חשוב לבדוק את עמוד הבית ועמוד "תודה" אם יש כזה.
