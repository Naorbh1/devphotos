# מאתר קודי תקלות – נאור פיקס

טבלה אינטראקטיבית להדבקה באתר: הלקוח בוחר יצרן, בוחר סוג מכשיר, מזין את קוד
השגיאה שמופיע בצג – ומקבל מיד את המשמעות, מה לבדוק לבד ומתי צריך טכנאי.
במקביל מוזרק לדף Schema (JSON-LD) שמנועי החיפוש קוראים, בלי שהוא מוצג ללקוח.

---

## ⚠️ לקרוא לפני שמעלים לאתר

**הקודים שנמצאים כרגע במערכת הם ידע כללי ולא אומתו מול ספרי שירות של היצרנים.**
הם מכסים את התקלות הנפוצות ונכונים ברוב הדגמים, אבל קודים משתנים בין דגמים ובין
שנות ייצור. שני דברים שכדאי לעשות לפני פרסום:

1. לעבור על המותגים שאתה הכי מתעסק איתם ולתקן/לאשר את הקודים מהניסיון שלך.
2. להעביר לי את המסמכים (ספרי שירות, טבלאות יצרן) – אני מחליף את הנתונים
   במה שכתוב בהם, וכל השאר (עיצוב, לוגיקה, Schema) נשאר בדיוק אותו דבר.

בינתיים מוצגת בטבלה הערת אחריות בתחתית, שאפשר לערוך ב-`data/site.json`.

## שלב 1 – למלא את הפרטים שלך

לפני הכל, ערוך את `data/site.json`:

```json
"phone": "050-0000000",              ← הטלפון שמוצג על הכפתור
"phoneE164": "+972500000000",        ← אותו מספר בפורמט בינלאומי (לחיוג בנייד)
"whatsapp": "972500000000",          ← מספר וואטסאפ, בלי + ובלי אפס מוביל
"url": "https://www.naorfix.co.il/", ← כתובת האתר האמיתית
"areaServed": ["תל אביב", ...],      ← אזורי השירות (נכנס ל-Schema)
"brandColor": "#0d6efd",             ← צבע ראשי, כדאי להתאים לצבע האתר
"accentColor": "#ff7a18"             ← צבע כפתור "בדיקת הקוד"
```

ואז להריץ:

```bash
python3 error-codes/build.py
```

הפלט נכתב ל-`error-codes/dist/`.

## שלב 2 – מה להדביק בדף הראשי

| קובץ | מה זה | מתי להשתמש |
|---|---|---|
| `embed-full-lite.html` | הטבלה + אינדקס מקוצר + Schema | **ברירת המחדל לדף הראשי** (269KB, ~37KB אחרי דחיסה) |
| `embed-full.html` | הטבלה + אינדקס מלא + Schema | אם רוצים את כל 238 הקודים באותו דף |
| `embed-widget.html` | רק הטבלה | אם ה-SEO יושב בדף נפרד |
| `embed-seo.html` | רק האינדקס + Schema | לדף ייעודי "קודי תקלות" |
| `schema.jsonld` | רק ה-Schema | להזרקה דרך הגדרות ה-SEO של הפלטפורמה |
| `pages/*.html` | דפי נחיתה ליצרן+מכשיר | ראה שלב 4 |
| `index.html` | תצוגה מקדימה מקומית | לפתוח בדפדפן לבדיקה, **לא להעלות** |

פותחים את הקובץ, מעתיקים את כל התוכן ומדביקים ב-HTML של הדף. אין תלות בשום
ספרייה חיצונית, וכל שמות המחלקות מתחילים ב-`nfx-` כדי לא להתנגש בעיצוב האתר.

### לפי פלטפורמה

**וורדפרס:** בעורך בלוקים – בלוק "HTML מותאם אישית" (Custom HTML), להדביק, לשמור.
זה עובד גם לטבלה וגם ל-Schema.

**Wix:** יש כאן מלכודת שחשוב להכיר. הרכיב "הטמעת קוד / Embed HTML" של Wix מציב
את הקוד בתוך iframe, וגוגל **לא** מייחס Schema שנמצא בתוך iframe לדף עצמו.
לכן ב-Wix:

- את **הטבלה** (`embed-widget.html`) מדביקים ברכיב ההטמעה הרגיל.
- את **ה-Schema** מזריקים בנפרד: הגדרות → Custom Code → הוספת קוד ל-`<head>`,
  ומדביקים את התוכן של `schema.jsonld` עטוף כך:
  `<script type="application/ld+json"> ... </script>`
- את **האינדקס** (`embed-seo.html` בלי ה-Schema) עדיף לבנות כדף Wix רגיל, או
  לוותר עליו בדף הראשי ולהשתמש בדפי הנחיתה של שלב 4.

**HTML רגיל / כל פלטפורמה אחרת:** פשוט להדביק במקום הרצוי בדף.

## שלב 3 – איך זה עובד ללקוח

- בחירת יצרן מעדכנת אוטומטית את רשימת סוגי המכשירים – מוצגים רק מכשירים
  שיש להם קודים אצל אותו יצרן.
- מתחת לשדות מופיעים "קודים נפוצים" כצ'יפים – לחיצה מציגה מיד את ההסבר.
  זה מוריד חיכוך למי שלא יודע להקליד את הקוד.
- החיפוש סלחני: `e-18`, `E18`, `f18`, `E 18` – כולם מגיעים לאותה תוצאה.
  גם בלבול נפוץ בין `O` ל-`0` ובין `I` ל-`1` (סמסונג ו-LG) מטופל.
- קוד שלא נמצא מציג "האם התכוונת ל…" עם הקודים הקרובים, ואם אין – פנייה
  ישירה לטלפון/וואטסאפ. **כל מסך שלא מסתיים בתשובה מסתיים בהפניה אליך.**
- כל חיפוש נשלח ל-`dataLayer` כאירוע `nfx_error_code_lookup` עם היצרן, סוג
  המכשיר, הקוד והאם נמצא. אם יש לך Google Tag Manager, אפשר לראות בדיוק אילו
  קודים אנשים מחפשים – זה בדיוק המידע שאומר איזה תוכן להוסיף הלאה.

## שלב 4 – התנועה האורגנית האמיתית

חשוב שתדע את זה לפני שתשקיע ציפיות: **Schema לבד לא מביא תנועה.** מאז 2023
גוגל מציג תוצאות FAQ מורחבות כמעט רק לאתרי ממשל ובריאות, כך שהסימון עוזר
להבנת התוכן – אבל מה שמדרג בפועל זה שיהיה תוכן אמיתי, בדף אמיתי, עם כתובת
משלו.

לכן הבנייה מייצרת גם 34 דפי נחיתה מוכנים ב-`dist/pages/`, אחד לכל
יצרן+מכשיר, למשל `bosch-washer.html` = "קודי תקלות בוש מכונת כביסה". כל דף
כולל כותרת ותיאור מותאמים, טבלת קודים, הסבר מלא לכל קוד, הטבלה האינטראקטיבית
עם היצרן שכבר נבחר מראש, ו-Schema משלו.

הדפים האלה הם שמביאים חיפושים מסוג "בוש E18", "סמסונג 4E מכונת כביסה" –
ואלה חיפושים של אנשים עם מכשיר מקולקל, כלומר לקוחות פוטנציאליים. מומלץ
להעלות אותם תחת `/error-codes/bosch-washer/` ולקשר אליהם מהדף הראשי.

**מה לא לעשות:** לא להסתיר את התוכן ב-`display:none` כדי שרק גוגל יראה אותו.
זו הפרה של ההנחיות ועלולה לגרור עונש. האינדקס כאן בנוי כאקורדיון שנפתח
בלחיצה – התוכן נגיש למשתמש, גוגל קורא אותו, והכל תקין. ה-Schema עצמו באמת
בלתי נראה, וזה בסדר גמור – זה הייעוד שלו.

## הוספה ועדכון של קודים

כל הנתונים יושבים ב-`data/codes/<משפחה>.json`. מבנה של קוד בודד:

```json
{
  "code": "E18",                    // הקוד כפי שמופיע בצג
  "alt": ["F18"],                   // כתיבים חלופיים שיובילו לאותה תוצאה
  "severity": "med",                // low = טיפול עצמי | med = בדיקה | high = להפסיק שימוש
  "title": "תקלת ניקוז – המים לא מתנקזים",
  "meaning": "משפט אחד שמסביר מה קרה",
  "causes": ["סיבה 1", "סיבה 2"],
  "steps": ["מה שהלקוח יכול לבדוק לבד"],
  "pro": "מתי כבר צריך טכנאי"
}
```

הוספת יצרן חדש: יוצרים `data/codes/<שם>.json` עם `"family": "<שם>"`, ומוסיפים
ב-`data/taxonomy.json` רשומת מותג עם `"codesFrom": "<שם>"`.

יצרן שמוכר מכשירים של יצרן אחר (למשל סימנס = בוש) לא צריך קובץ משלו – רק
`"codesFrom"` שמצביע על המשפחה הקיימת.

אחרי כל שינוי:

```bash
python3 error-codes/build.py     # בונה מחדש את כל קובצי ההדבקה
python3 error-codes/test_widget.py   # בדיקה בדפדפן שהכל עדיין עובד
```

הסדר בקובץ קובע מה נחשב "נפוץ": שלושת הראשונים בכל רשימה הם אלה שנכנסים
לגרסה המקוצרת (`embed-*-lite`). בתצוגה עצמה הקודים ממוינים לפי סדר טבעי.

## מבנה התיקייה

```
error-codes/
  data/
    site.json          פרטי העסק, צבעים, טקסטים
    taxonomy.json      יצרנים וסוגי מכשירים
    codes/*.json       הקודים עצמם, קובץ למשפחת יצרנים
  template/
    widget.html/css/js תבנית הטבלה – כאן משנים עיצוב והתנהגות
  build.py             בונה את הכל
  test_widget.py       בדיקות בדפדפן אמיתי
  dist/                הפלט – קובצי ההדבקה (נוצר מחדש בכל בנייה)
  screenshots/         תצוגות מקדימות: דסקטופ, מובייל ודף נחיתה
```
