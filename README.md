# פאנל דעות ישראלי מגוון - "חכמת ההמונים"

מאגר של פרופילים סינתטיים מגוונים של ישראלים דוברי עברית - שונים בגיל, מגזר,
נטייה פוליטית ואזור מגורים - שאפשר לשאול אותם שאלה ולקבל תמונה של איך קשת
רחבה של השקפות עולם בישראל הייתה מגיבה אליה.

**חשוב להבין:** אלה לא בני אדם אמיתיים ואלה לא תשובות של סקר אמיתי. זו סימולציה
מבוססת LLM (Claude) שמדמה נקודות מבט מגוונות לפי תיאור דמות. שימושי לגיבוש
אינטואיציה ולבדיקת "איך זה יתקבל אצל קהלים שונים", אבל אינו תחליף למחקר דעת
קהל אמיתי.

## מבנה

```
panel/
  generate_profiles.py   # יוצר את מאגר הפרופילים (panel/profiles.json)
  profiles.json           # ~220 פרופילים מגוונים (נוצר מראש, אפשר לייצר מחדש)
  ask.py                  # שואל שאלה את כל הפרופילים ומצרף תוצאות
  requirements.txt
```

כל פרופיל כולל: שם, גיל, מגדר, מגזר (חילוני / מסורתי / דתי-לאומי / חרדי-ליטאי
/ חרדי-חסידי / חרדי-ספרדי / ערבי-מוסלמי / ערבי-נוצרי / דרוזי / בדואי), אזור
מגורים, נטייה פוליטית, עיסוק, מצב משפחתי ותיאור קצר של ערכים.

## התקנה

```bash
pip install -r panel/requirements.txt
export ANTHROPIC_API_KEY="..."   # מפתח ה-API שלכם
```

## שימוש

שאלו שאלה את כל הפאנל:

```bash
python panel/ask.py "האם צריך להעלות את גיל הפרישה בישראל?"
```

הפלט כולל:
- התפלגות עמדות כללית (תומך / מתנגד / מעורב-תלוי / לא בטוח)
- פילוח לפי מגזר, נטייה פוליטית וקבוצת גיל
- ציטוטים מייצגים מכמה דמויות שונות

אפשרויות שימושיות:

```bash
# הרצה על תת-קבוצה קטנה, לבדיקה מהירה וזולה לפני הרצה מלאה
python panel/ask.py "השאלה שלכם" --limit 20

# שמירת כל התשובות הגולמיות (לניתוח נוסף)
python panel/ask.py "השאלה שלכם" --output results.json

# שינוי מודל / רמת מקביליות
python panel/ask.py "השאלה שלכם" --model claude-opus-5 --concurrency 30
```

## יצירת מאגר פרופילים חדש

```bash
python panel/generate_profiles.py --n 220
```

ניתן לשנות את `--n` (כמות הפרופילים) ואת ההתפלגות בין המגזרים בתוך
`generate_profiles.py` (המשתנה `SECTOR_WEIGHTS`).

## עלות והערות

כל הרצה על כל הפאנל שולחת קריאת API אחת לכל פרופיל (כ-220 קריאות). לפני
הרצה מלאה על שאלה חדשה, מומלץ לבדוק עם `--limit 20` כדי לוודא שהתוצאה
נראית הגיונית.

# איסוף עסקים מ-Google Maps

`maps/` היא ערכת כלים לאיסוף רשימות עסקים מ-Google Maps (שם, כתובת, טלפון,
אתר, דירוג, שעות וביקורות) וייצוא ל-CSV/JSON. היא עובדת מול Places API
הרשמי - לא גירוד HTML - ולכן דרושים מפתח API ותקציב קריאות.

```bash
pip install -r maps/requirements.txt
export GOOGLE_MAPS_API_KEY="..."

# אמידת עלות לפני הרצה
python maps/search.py "מסעדות" --location "תל אביב" --radius 5 --dry-run

# איסוף וייצוא
python maps/search.py "מסעדות" --location "תל אביב" --radius 5 --csv out.csv

# עוטף מקוצר: "שאילתה" lat lng radius_km -> CSV+JSON ב-out/
./scripts/scrape.sh "coffee shops in Austin TX" 30.2672 -97.7431 5
```

התיעוד המלא - כולל כיסוי אזורים רחבים מעבר לתקרת 60 התוצאות של ה-API, מפלסי
שדות ועלות, ומגבלות ידועות - נמצא ב-[maps/README.md](maps/README.md).
